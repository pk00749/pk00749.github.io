# 微信公众号文章写作

## 工作流程

### 1. 获取主题
- 等待用户提供文章主题
- 如主题涉及特定领域，可调用相关 skill 获取背景信息（如金融、体育、科技等）

### 2. 收集素材
- 使用 web_fetch 抓取与主题相关的权威文章（2-3 篇）
- 使用 news-aggregator skill 获取最新热点资讯
- 确保内容事实准确，来源可靠

### 3. 撰写文章
- 字数要求：默认 1000 字，可根据用户需求调整
- 内容要求：
  - 事实为主，不胡编乱造
  - 保持客观中立，避免极端言论
  - 如有争议话题，展示多方观点
- 排版要求：
  - 使用合适的标题
  - 使用 emoji 增加阅读体验
  - 段落清晰，重点突出
  - 适配微信公众号风格

### 4. 配图（如需要）
- 优先从抓取的网页中提取图片 URL
- 如无法提取，使用 qwen-image skill 生成配图
- 图片插入文章开头或适当位置

### 5. 输出
- 保存为 markdown 文件
- 格式：YYYY-MM-DD-文章标题.md
- 可选：推送到 GitHub 或创建公众号草稿

## 可调用技能

- `news-aggregator` - 获取热点新闻
- `toutiao-news-trends` - 获取头条热榜
- `tushare-finance` - 获取金融数据
- `qwen-image` - 生成配图
- `wechat-mp-article` - 发布到公众号草稿

## 注意事项

- 涉及政治敏感话题请谨慎处理
- 如不确定某些信息真实性，明确标注"以官方发布为准"
- 避免使用未经验证的小道消息
