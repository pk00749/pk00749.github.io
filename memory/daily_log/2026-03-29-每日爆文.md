# 太原火灾致3死23伤，现场画面曝光触目惊心

今天上午，太原突发大火，已造成3人死亡、23人受伤！🔥

说实话，这种新闻我真不想写。但看到了还是想提醒大家，意外真的就在身边。

据现场曝光的画面来看，最先起火的位置火势非常凶猛，浓烟滚滚。短短时间内，整栋建筑就被大火吞噬。

⚠️ 目前具体伤亡数字还在进一步统计中，起火原因也在调查中。

我看到评论区的网友都在说：太吓人了，这好好的人怎么说没就没了...

确实，明天和意外，你永远不知道哪个先来。

就在昨天，有朋友还跟我说要珍惜当下。现在想想，真的不是矫情。

🙏 希望伤者平安，也希望这样的悲剧不要再发生。
