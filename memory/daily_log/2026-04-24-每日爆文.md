# 26岁女生穿袜子睡觉，结果脚趾甲全变厚了 😱

说实话，我看到这个热搜第一反应是：**这也太离谱了吧？**

结果点进去一看，好多人都在评论区说"我也这样"、"难怪我的脚气一直不好"……

## 到底啥情况？

据博主分享，她因为手脚冰凉，常年穿着袜子睡觉🧦，一穿就是好几年。

结果最近发现脚趾甲变得又厚又黄，剪都剪不动，医院一查——**"灰指甲"**，还是多层的！

医生说就是因为脚一直闷在袜子里，不透气 + 潮湿，真菌繁殖开了。

## 原理很简单

👇 敲重点了：

- 🌙 晚上睡觉时，脚部会出汗
- 🧦 穿上袜子，汗全闷在里面
- 🦠 温暖潮湿的环境 = 真菌的天堂
- 💅 真菌跑到指甲里，就会让指甲变厚、变黄、变形

这就是传说中的**"千层甲"**……

1. ❌ 睡觉别穿袜子，让脚透气
2. ❌ 也不要用太厚的被子捂脚
3. ✅ 如果真的手脚冰凉，睡前泡热水脚♨️
4. ✅ 穿透气性好的棉质袜子，白天穿就行
