# 睡觉时被空调砸头！酒店这个隐形杀手你家可能也有

🤯 朋友们，昨晚上热搜的一个新闻给我看醒了。

有个网友发帖说，自己住酒店正睡着觉呢，**空调突然掉下来了**，正好砸在头上！想想都后怕，这要是有个三长两短……

好在人没什么大事，但评论区已经炸锅了：

> “这也太危险了吧？空调怎么会掉下来？”
> “我上次住酒店都不敢开空调，原来是怕这个？”
> “赶紧看看自己家的空调有没有问题！”

说实话，我以前也没想过这个问题。空调装在墙上，好好的怎么会掉下来？

但仔细一想，还真是有可能的：

**安装不规范** → 很多安装师傅图省事，打的膨胀螺丝不够深，或者根本没拧紧
**墙体问题** → 出租屋或者老房子的墙面可能根本承受不住空调的重量
**时间久了松动** → 用的年数多了，支架生锈、螺丝松动，谁知道什么时候会掉

而且不光是酒店，自己家里也很危险！尤其是租的房子，那些空调不知道装了多少年了。

🔥 **所以大家赶紧检查一下：**

1. 看空调有没有明显倾斜
2. 用手轻轻推一下，看看晃不晃
3. 听有没有奇怪的响声
4. 检查一下支架和螺丝

如果发现有问题，**千万别自己动手**，赶紧找专业的来修。

还有，住酒店的时候尽量别正对着空调睡，虽然概率低，但万一呢？

我把这事跟身边朋友说了，结果有人说：“那我以后住酒店都睡地上算了！” 😂

虽然是句玩笑话，但也能看出来大家是真的怕了。

**生命安全真的不是小事。**
