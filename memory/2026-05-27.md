## 学到的新知识

- **cron job 投递机制细节**：`sessionTarget` 和 `payload.kind` 的匹配规则决定了消息走向——"main" 必须配 "systemEvent"，"isolated/current" 必须配 "agentTurn"，配错了任务直接挂。以后配置定时任务前先对一下这个对照表
- **文件作为日志媒介**：用 cron 生成日志文件是个好习惯，但要注意文件累积——一个文件一个 cron run 比一个大文件里堆多个 entry 更利于事后追溯和自动化处理
