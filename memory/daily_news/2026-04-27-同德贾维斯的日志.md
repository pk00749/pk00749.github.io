### 详细 AI 新闻

#### 1. DeepSeek-V3 (103,242 ⭐)
*GitHub Trending | 今日最高星标项目*

**摘要**：DeepSeek-V3 是强大的 MoE 语言模型，总参数 671B，激活 37B/token。采用 MLA 和 DeepSeekMoE 架构，首创无辅助损失负载均衡策略，多令牌预测训练目标。训练数据 14.8 万亿 token，训练仅需 2.788M H800 GPU 小时。性能超越其他开源模型，比肩闭源领先模型。

**点评**：DeepSeek-V3 的开源标志着中国 AI 团队在大模型领域的核心竞争力，其高效训练架构和开源策略正在重塑全球 AI 竞争格局。

#### 2. TradingAgents (54,218 ⭐)
*GitHub Trending | 多代理金融交易框架*

**摘要**：TradingAgents 是多代理 LLM 金融交易框架，模拟真实投资公司运作。由基本面分析师、情绪专家、技术分析师、交易员、风险管理团队等多代理协同评估市场状况并进行交易决策。近期发布 v0.2.4，新增结构化输出代理、LangGraph 检查点恢复、DeepSeek/Qwen/GLM/Azure 支持。

**点评**：金融领域是 AI agent 最快落地的场景之一，TradingAgents 的多代理架构为量化交易提供了新的研究范式。

#### 3. Microsoft VibeVoice (43,624 ⭐)
*GitHub Trending | 微软开源语音 AI*

**摘要**：VibeVoice 是微软开源前沿语音 AI 家族，包含 TTS 和 ASR 模型。VibeVoice-ASR 是统一语音转文本模型，支持 60 分钟长音频单次转录，生成包含说话者、时间戳和内容的结构化转录，支持用户自定义上下文。原生支持 50+ 语言。VibeVoice-Realtime-0.5B 支持实时流式文本转语音。

**点评**：微软在语音 AI 领域持续投入，VibeVoice 的开源降低了语音交互的技术门槛，对语音助手、会议转录等应用是重大利好。

#### 4. beads (22,405 ⭐)
*GitHub Trending | Agent 记忆升级*

**摘要**：Beads 是为 coding agent 打造的记忆升级工具，提供持久化、结构化的图结构记忆管理。替代混乱的 markdown 计划，用依赖感知的图结构帮助 agent 处理长周期任务而不丢失上下文。基于 Dolt 版本控制数据库，支持 cell 级合并、原生分支和同步。

**点评**：长上下文管理是当前 agent 落地的核心瓶颈，beads 的图结构记忆方案值得关

#### 5. claude-code-templates (25,938 ⭐)
*GitHub Trending | Claude Code 配置工具*

**摘要**：Claude Code Templates (aitmpl.com) 是 Anthropic Claude Code 的即用配置集合。提供 AI agents、自定义命令、设置、外部集成 (MCPs) 和项目模板。包含安全审计员、React 性能优化器、数据库架构师等专业 agents，/generate-tests、/optimize-bundle 等命令，GitHub、PostgreSQL、Stripe、AWS、OpenAI 等 MCP 集成。

**点评**：随着 Claude Code 用户增长，生态工具和模板需求旺盛，该项目降低了团队配置成本。
