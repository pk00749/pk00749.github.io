# 渔知道 PRD

_Version 3.0 | 正式命名版 | 更新于 2026-07-29_

> 以四大家鱼为切入点，最终扩展为多品种水产行情追踪平台

---

## 一、项目概述

### 1.1 产品定位

**渔知道** —— 面向水产从业者和投资者的实时价格监测与决策支持工具。

名字含义：让每一尾鱼的价值"被知道"，让从业者不再凭运气卖鱼。

类比"猪周期"之于养猪业，本产品要做水产领域的**价格波动预警系统**，把天气、运输、饲料、国际环境等因素整合分析，提前传递信号给需要的人。

### 1.2 核心价值

- **对从业者（养殖户/贸易商）**：告诉什么时候出塘、什么时候压塘、什么时候备货
- **对饲料/经销商**：提供定价参考和客户黏性工具
- **对投资者**：给A股水产板块提供择时参考依据
- **对整个产业**：提高信息透明度，减少"赌运气"式的经营决策

### 1.3 目标用户与付费意愿分析

| 用户群体 | 核心需求 | 付费意愿 | 策略 |
|---------|---------|---------|------|
| **饲料企业/经销商** | 定价参考、客户黏性工具 | ⭐⭐⭐⭐⭐ 高 | **核心B端付费用户** |
| 批发商/贸易商 | 判断采购时机 | ⭐⭐⭐ 中 | 推送SaaS工具 |
| 养殖户/养殖场 | 什么时候出塘能卖最高价 | ⭐ 极低 | **免费用户**，积累流量 |
| 投资者/二级市场 | A股择时依据 | ⭐⭐ 中 | 专业版/机构版 |
| 金融机构 | 风险评估 | ⭐⭐⭐ 中 | 机构版定制 |

> ⚠️ **关键修正**：一线养殖户付费意识极弱，不应作为主要付费目标。B端饲料/经销商才是核心收入来源，养殖户是免费流量池。

### 1.4 发展路径

- **第一期（当前）**：四大家鱼（草鱼、青鱼、鲢鱼、鳙鱼）数据采集 + 行情看板
- **第二期**：扩展到南美白对虾、小龙虾等高波动品种
- **第三期**：多品种并行，成为综合水产行情平台

## 四、功能模块

### 4.1 行情看板（核心功能）

- **多品种实时价格**：按品种/产区/规格筛选
- **历史价格走势**：日/周/月线可切换
- **历史季节性规律**：过去5年同月平均价格作为参考基准
- **价格预警**：高于/低于阈值自动提醒（微信推送）
- **多市场对比**：不同批发市场价格横向对比
- **塘口价参考**：通过产区-销区价差估算，标注估算方法和误差范围

> ⚠️ **塘口价估算说明**：由于不同产区物流成本差异大、损耗率受季节影响，此功能仅在数据充分时展示估算值，并明确标注"估算值仅供参考"。不做精确承诺。

### 4.2 影响因素追踪

- **天气地图**：台风/暴雨/洪涝路径与主产区叠加显示
- **水温监测**：夏季高温预警（>32℃持续天数对四大家鱼有影响）
- **饲料成本看板**：豆粕/玉米期货价格+趋势，直接影响养殖成本
- **病害预警**：水产病害通报（烂鳃/肠炎/寄生虫等）区域分布
- **替代品价格**：鲤鱼/鲫鱼/罗非鱼价格联动

### 4.3 供给分析

- **养殖面积数据**：各品种主产区养殖面积变化
- **投苗/出塘节奏**：基于历史规律的季节性参考
- **供需平衡表**：月度供需差（基于历史数据的估算，非预测）

| 项目 | 本月实际 | 下月参考 |
|------|---------|---------|
| 产量 | X万吨 | 历史均值参考 |
| 进口 | X万吨 | 历史均值参考 |
| 消费 | X万吨 | 历史均值参考 |
| 期末库存 | X万吨 | 历史均值参考 |
| **供需差** | **X万吨** | **历史季节性参考** |

### 4.4 预测模型

> ⚠️ **MVP阶段砍掉此模块**，预测功能在v2.0后数据积累充足时再上线。

**v2.0规划（数据积累10年以上后启动）：**

- **产量预测**：ARIMA / 线性回归（需要10年以上年度数据）
- **价格预测**：多元回归（产量 + 季节 + 饲料成本）（需要5年以上季度数据）
- **天气影响量化**：水温/洪涝对亩产的影响弹性系数

**MVP阶段替代方案**：
- 仅展示**历史季节性规律**（过去5年同月均价、最高价、最低价）
- 不做预测，只做参考基准
- 天气事件以标注形式叠加在图表上

### 4.5 报告中心

- **每日行情早报**：每日推送，重点品种价格点评
- **周报/月报**：周期性的供需分析
- **专题报告**：洪涝影响、禁渔期等事件驱动分析
- **投资参考**：A股水产板块联动分析

## 七、数据库设计

### 7.1 核心表结构

```sql
-- 产量数据表
CREATE TABLE production (
    id SERIAL PRIMARY KEY,
    year INT NOT NULL,
    province VARCHAR(50),
    species VARCHAR(50),                  -- 品种：grass carp/silver carp/bighead carp/common carp
    output_tons DECIMAL(10,2),
    area_hectare DECIMAL(10,2),
    seedlings_billion DECIMAL(10,2),      -- 亿尾
    yield_per_mu DECIMAL(8,2),
    source VARCHAR(100),
    url TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 价格数据表
CREATE TABLE price (
    id SERIAL PRIMARY KEY,
    date DATE NOT NULL,
    species VARCHAR(50),
    region VARCHAR(50),
    market_level VARCHAR(20),             -- 'farm'/'wholesale'/'retail'
    product_type VARCHAR(50),             -- 'live'/'fresh'/'frozen'
    spec_gram INT,                        -- 规格（克/尾）
    price_yuan_per_jin DECIMAL(8,2),
    source VARCHAR(100),
    url TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 饲料成本数据表
CREATE TABLE feed_cost (
    id SERIAL PRIMARY KEY,
    date DATE NOT NULL,
    soybean_meal_price DECIMAL(8,2),      -- 豆粕价格（元/吨）
    corn_price DECIMAL(8,2),              -- 玉米价格（元/吨）
    source VARCHAR(100),
    created_at TIMESTAMP DEFAULT NOW()
);

-- 天气事件表
CREATE TABLE weather_events (
    id SERIAL PRIMARY KEY,
    event_date DATE NOT NULL,
    species VARCHAR(50),
    event_type VARCHAR(50),               -- 'typhoon'/'flood'/'high_temp'/'disease'
    region VARCHAR(50),
    severity VARCHAR(20),                 -- 'warning'/'moderate'/'severe'
    description TEXT,
    source VARCHAR(100),
    url TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 天气数据表
CREATE TABLE weather_data (
    id SERIAL PRIMARY KEY,
    date DATE NOT NULL,
    region VARCHAR(50),
    water_temp DECIMAL(5,2),              -- 水温（℃）
    air_temp DECIMAL(5,2),                -- 气温（℃）
    precipitation_mm DECIMAL(6,2),        -- 降水量（mm）
    source VARCHAR(100),
    created_at TIMESTAMP DEFAULT NOW()
);
```

## 九、竞争分析

### 9.1 现有竞品

| 竞品 | 优点 | 不足 |
|------|------|------|
| 农业农村部价格系统 | 官方权威 | 无分析、界面老旧、无移动端 |
| 布瑞克农业数据 | 数据全 | 收费贵、主要聚焦农业不专注水产 |
| 中国水产养殖网 | 行业垂直 | 无移动端、界面过时、非标准化 |
| 卓创资讯 | 数据分析 | 收费高、主要聚焦工业品 |

### 9.2 差异化机会

1. **淡水鱼垂直+分析智能化**：现有竞品要么太泛、要么太旧
2. **移动端优先**：现有竞品大多PC端，移动体验差
3. **价格预警**：没人做得好的功能
4. **饲料成本联动**：豆粕/玉米期货直接传导到养殖成本分析
5. **投资联动**：A股水产板块行情联动分析，目前空白

### Phase 1.5 —— 冷启动验证（第3个月）

**核心目标：验证真实需求，而非凑热闹**

- [ ] 100人内测，留存率 > 30%（7日内回访）
- [ ] 至少10人主动询问"什么时候能付费"
- [ ] 日活用户 > 20%
- [ ] B端用户（饲料/贸易商）占比 > 10%

**验证指标定义：**
| 指标 | 达标值 | 测量方式 |
|------|-------|---------|
| 留存率 | > 30% | 7日内回访人数/注册人数 |
| 付费意向 | > 10人主动问 | 客服对话记录 |
| 日活 | > 20% | DAU/注册用户 |
| B端占比 | > 10% | 用户画像/来源统计 |

**验证失败应对：**
- 重新调研目标用户需求
- 调整产品定位或功能优先级
- 暂停Phase 2，直到问题定位清楚

**验证成功标准：** 至少3项指标达标 → 继续Phase 2
