# 骗了吗 — 项目计划书

> 骗局数据库：让骗子无处遁形，让普通人不再上当。

---

## 1. 项目概述

**一句话定位：**
中文互联网最全的骗局案例库——粘贴骗子的原话，三秒判断你是不是正在被骗。

**核心用户：**
已遇到某人或某事，**怀疑自己正在被骗，想验证**的人。

**核心价值：**
骗子的话术在变，但套路不变。80% 的骗局都是已知套路的变体。知道这个套路，就能识别这个骗局。

**变现模式：** 广告

---

## 2. 用户场景

### 主要场景（核心用户）

> 用户在微信/QQ/社交软件里跟一个人聊着，对方说了些话、推荐了个平台、提了个投资机会。用户心里隐约觉得不对劲，但不确定是不是骗子。
>
> 他复制对方说的话，粘贴到"骗了吗"搜索框 → 匹配到对应骗局 → 看到红旗预警对照表 → 确认自己正在被骗 → 分享给朋友/报案。

### 次要场景

- B：看到一个机会（投资、兼职），想确认靠不靠谱
- C：纯粹学习防骗知识

## 3. 功能设计

### 3.1 核心功能（MVP）

#### 首页
- 搜索框（最大最显眼，提示语："粘贴骗子说过的话试试"）
- 分类入口（10大分类，每类一句话描述）
- 热门标签云
- 今日热骗（按时间热度排序，最新 + 搜索最多）

#### 搜索结果页
- 按关键词模糊匹配骗局列表
- 高亮匹配关键词
- 排序：热度优先
- 搜不到 → 引导投稿

#### 骗局详情页
- 骗局名称 + 严重程度（高/中/低）
- 分类标签
- **红旗预警对照表**（左：骗子说的话 | 右：红旗解释，逐条对照）
- 骗子话术还原
- 真实案例（脱敏，显示"热心用户提供"）
- 如果你正在经历（行动指南）
- 相关骗局推荐
- 分享按钮（微信卡片、复制链接、海报生成）

#### 分类浏览页
- 10大分类，每个分类一句话描述
- 点击进入子类列表

#### 投稿功能
- 必填字段：骗局类型（10选1）、骗子用了什么话术、涉案金额或损失物品
- 选填字段：大概经过
- 提交后人工审核
- 审核通过后公开，显示"热心用户提供"（完全匿名）

### 3.2 扩展功能（V2）

- AI 对话识别：用户描述情况，AI 判断是否是骗局
- 骗局订阅：订阅特定类型骗局的最新案例
- 邮件/推送通知：投稿审核结果通知

## 4. 数据结构

### 4.1 骗局条目（Scam）

```typescript
interface Scam {
  id: string;                    // 唯一标识
  title: string;                 // 骗局名称，如"杀猪盘"
  slug: string;                  // URL 友好 slug

  // 分类（入口）
  category: string;              // 主分类名称
  categorySlug: string;           // 主分类 slug

  // 标签（定位）
  tags: string[];                // 标签，如["网恋", "投资", "高风险"]

  // 严重程度
  severity: 'high' | 'medium' | 'low';
  // 涉案金额区间
  amountRange: string;           // 如"几千-几十万"

  // 骗子话术
  scripts: string[];             // 典型对话/话术

  // 红旗预警（左：骗子说 | 右：解释）
  redFlags: {
    script: string;               // 骗子说的原话
    explanation: string;           // 红旗解释
  }[];

  // 真实案例摘要（脱敏）
  cases: {
    summary: string;              // 案例摘要
    amount: string;               // 涉案金额
    contributor: '热心用户提供';  // 固定显示匿名
  }[];

  // 行动指南
  actions: string[];             // 如果正在经历，该怎么做

  // 数据来源
  sourceUrl?: string;             // 来源链接（公安部、裁判文书网等）
  sourceName?: string;           // 来源名称，如"公安部刑侦局"

  // 元数据
  publishedAt: string;            // 发布时间
  updatedAt: string;             // 更新时间
  viewCount: number;             // 浏览次数
  hotScore: number;              // 热度分
}
```

### 4.2 分类体系（10大分类）

| 编号 | 分类名称 | 一句话描述 | 关键词 |
|------|---------|-----------|--------|
| 1 | 冒充客服诈骗 | 骗子冒充各类平台客服，用"账户异常"、"退款理赔"、"包裹丢失"等借口，诱导你转账或泄露账户信息。 | 客服来电、包裹问题、退款验证码 |
| 2 | 杀猪盘诈骗 | 通过网络交友建立情感信任后，以"带你赚钱"、"投资平台"、"博彩内幕"等理由诱导转账。 | 网恋、导师、带单、平台投资 |
| 3 | 虚假购物诈骗 | 在电商平台、二手网站发布低价商品、虚假交易信息，收款后不发货或发假货。 | 闲鱼、拼多多、私聊链接、微信交易 |
| 4 | 求职兼职诈骗 | 以"刷单返利"、"打字员"、"先缴费后上岗"为诱饵，骗取押金、培训费或刷单本金。 | 刷单、点赞、日结、押金、轻松赚钱 |
| 5 | 冒充公检法诈骗 | 骗子冒充公安、检察院、法院人员，用"涉嫌洗钱"、"通缉令"、"资金核查"等话术让你转账到"安全账户"。 | 警官、检察官、涉及案件、洗黑钱、转账 |
| 6 | 预付消费陷阱 | 办理健身卡、美容卡、教育培训预付卡后，商家卷款跑路或服务严重缩水。 | 办卡、充值、预付、会员卡、健身房 |
| 7 | 网络贷款诈骗 | 以"低息"、"无抵押"、"秒批"为诱饵，要求先交手续费、保证金，或让你签空白合同。 | 贷款、利息、保证金、流水、审核 |
| 8 | 养老健康诈骗 | 针对老年人推销虚假保健品、养老服务、投资项目，骗取养老钱。 | 保健品、灵芝、养老基地、神药、健康讲座 |
| 9 | 婚恋彩礼诈骗 | 以相亲、结婚为名索要彩礼、见面礼、金首饰，收到钱后人消失或不断索要。 | 相亲、彩礼、订婚、金器、媒人 |
| 10 | 生活服务陷阱 | 日常生活中遇到的面对面消费欺诈，包括旅游团强迫消费、景区宰客、虚假促销等。 | 旅游团、景区、缺斤少两、路边摊、网红店 |

### 4.3 标签体系（多选，用于精确定位）

```
诱饵类型：# 感情 # 赚钱 # 恐惧 # 省钱 # 求职
技术手段：# 虚假App # 钓鱼链接 # 屏幕共享 # AI换脸 # 伪基站
钱没了：# 先小额返利 # 充值解冻 # 交税提现 # 保证金 # 跑分
情感操控：# 嘘寒问暖 # 叫亲密称呼 # 炫富 # 卖惨 # 催紧迫
```

## 5. 技术方案

### 5.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端框架 | **Next.js 14 (App Router)** | Vercel 原生支持，SSR/SSG 灵活切换 |
| 编程语言 | **TypeScript** | 类型安全，减少 bug |
| 样式 | **Tailwind CSS** | 快速开发，一致性设计 |
| 数据库 | **Supabase (PostgreSQL)** | 免费额度够用，Vercel 集成方便 |
| 搜索 | **Supabase 全文搜索（模糊匹配）** | MVP 阶段足够，支持模糊匹配 |
| 部署 | **Vercel** | 目标平台 |
| 图标 | **Lucide React** | 开源图标库 |
| 内容管理 | **MDX / 本地 JSON** | MVP 用 JSON seed，不上 CMS |
